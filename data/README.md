# Données

Les données utilisées dans ce projet sont destinées à l'analyse de profils et de compétences.

Le fichier de données sera placé dans ce dossier.

Les données originales du travail universitaire ne sont pas intégrées au dépôt lorsqu'elles ne peuvent pas être redistribuées.

Le projet pourra être reproduit avec un jeu de données public présentant une structure comparable.
