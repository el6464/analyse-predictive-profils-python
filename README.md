# Analyse prédictive des profils et compétences avec Python

## Présentation

Ce projet porte sur l'analyse de profils et de compétences dans le but d'étudier leur relation avec l'adéquation à des opportunités professionnelles.

L'objectif est de mettre en œuvre une démarche complète de Machine Learning :

- préparation des données ;
- analyse exploratoire ;
- transformation des variables ;
- entraînement de plusieurs modèles ;
- comparaison des performances ;
- optimisation des hyperparamètres ;
- évaluation des résultats.

## Problématique

Dans quelle mesure les compétences et caractéristiques observées dans les données permettent-elles de différencier les profils selon leur adéquation à une opportunité professionnelle ?

## Méthodologie

Le projet suit les étapes suivantes :

1. Importation des données
2. Nettoyage
3. Analyse exploratoire
4. Statistiques descriptives
5. Analyse des corrélations
6. Encodage des variables catégorielles
7. Séparation des données d'entraînement et de test
8. Entraînement des modèles
9. Comparaison des performances
10. Recherche d'hyperparamètres
11. Évaluation
12. Interprétation des résultats

## Modèles étudiés

Plusieurs algorithmes de classification sont comparés :

- Régression logistique
- Arbre de décision
- Random Forest
- K-Nearest Neighbors (KNN)

## Python

Le projet utilise notamment :

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Évaluation

Les modèles sont comparés à partir de plusieurs indicateurs de performance, notamment :

- accuracy ;
- précision ;
- rappel ;
- F1-score ;
- matrice de confusion.

L'objectif n'est pas uniquement d'obtenir une bonne performance mais également de comparer les modèles et d'interpréter leurs résultats.

## Optimisation

Une recherche d'hyperparamètres est réalisée afin d'identifier des configurations plus adaptées pour certains modèles.

## Limites

Les performances d'un modèle dépendent notamment de la qualité des données, des variables disponibles et de la représentativité de l'échantillon.

Les résultats prédictifs doivent être interprétés dans le contexte des données utilisées.

## À propos

Projet réalisé dans le cadre d'un travail universitaire en Data Analysis et Machine Learning.
