## Analyse des résultats

L'analyse ne se limite pas à la performance prédictive des modèles.

Une analyse de l'importance des variables permet également d'identifier les caractéristiques qui contribuent le plus à la classification des profils.

Les caractéristiques moyennes des étudiants sont également comparées entre les différents profils afin de mieux comprendre leurs différences.

Cette approche permet de combiner :

- analyse descriptive ;
- analyse statistique ;
- visualisation ;
- modélisation prédictive ;
- interprétation des résultats.
